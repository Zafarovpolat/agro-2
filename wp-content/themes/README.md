# AgroNord WordPress theme

`agronord/` is the production WordPress theme used by AgroNord.

- Install path: `wp-content/themes/agronord/`
- Depends on the active `AgroNord — каталог техники` plugin.
- Editable global data (phone, messengers, e-mail, address and footer text) comes from the plugin's **Настройки AgroNord** page.
- The logo can be changed through **Внешний вид → Настроить → Логотип**; the theme falls back to `assets/logo.svg` when no custom logo is set.
- Navigation is managed through WordPress menus; the theme provides `primary` and `footer` menu locations.

This directory is a source snapshot of the theme and does not contain hosting credentials or database exports.
