# AgroNord — сайт сельхозтехники (Молдова)

Статический многостраничный сайт: **HTML + CSS + vanilla JS**, без сборки и внешних зависимостей.
Доработка от 02.10.2026 — по пожеланиям клиента: **статусы техники, счётчик поставки, бронирование**.

## Что нового (по запросу клиента)

| Пожелание клиента | Как сделано |
|---|---|
| Статус товара «в дороге» и фото для таких позиций | 4 статуса: **в наличии / в дороге / забронировано / продан**. У каждой позиции есть фото, цена, серия и контейнер |
| Стикер в карточке | Метка на фото в цветах дизайн-системы: «В наличии» — зелёная, «В дороге» — янтарная, «Забронировано» — тёмная, «Продан» — серая (и фото приглушается) |
| «Осталось 55 дней» — считать автоматически | Блок счётчика + полоса прогресса. Считается в браузере от даты прибытия, поэтому цифры всегда актуальны |
| Кнопка не «Купить», а «Забронировать» | У позиций в пути — «Забронировать», у техники в наличии — «Оставить заявку» |
| Форма: имя, фамилия, телефон | Модальное окно с полями Имя / Фамилия / Телефон / комментарий и галочкой согласия |
| Стикер «Забронировано» после предоплаты | Менеджер нажимает «Подтвердить бронь» в админке — на витрине появляется стикер, кнопка блокируется |
| Управление вручную, без автоматики | Демо-админка `admin.html`: статус, срок поставки, дата прибытия, очередь заявок |
| Взять идеи с сайта-образца | Фильтр «только свободные», сортировка по дате прибытия, поиск по серийному номеру, блок «Контейнеры в пути», условия скидок, подпись «каталог обновлён», кнопка WhatsApp с текстом о конкретном экземпляре, блок «Как купить» |

### Логика счётчика поставки

Считается в браузере посетителя от **даты прибытия** и сегодняшнего дня (иначе в кеше «застынет» одно и то же число).

| Ситуация | Иконка | Что видит клиент |
|---|---|---|
| В пути, срок не близко | грузовик | **До прибытия 55 дней** · поставка ожидается 26.11.2026 · полоса прогресса «5 из 60 дней прошло» |
| Осталось ≤ 7 дней | часы | **Ожидается со дня на день** · тот же спокойный блок, янтарная иконка |
| Срок истёк | треугольник | **Рейс задерживается** · точную дату подтверждает менеджер — без отрицательных чисел. Единственное состояние с цветным фоном |
| Уже в стране | галочка | **В Молдове с 20.09.2026** — счётчик заменяется фактом |
| Продан | — | Счётчика нет, кнопка «Смотреть похожие» |

## Дизайн-система

Все новые блоки собраны из существующих переменных `css/style.css`. Что важно:

- **Одна семантика цвета.** Цвета статусов живут в `:root` (`--st-stock-*`, `--st-transit-*`, `--st-reserved-*`,
  `--st-sold-*`, `--st-late-*`) и используются стикерами, счётчиком, плашками и контейнерами. Пар «текст на фоне»
  вне токенов в правилах нет, контраст каждой проверен на AA (≥ 4.5:1) для кегля 12.5px.
- **Иконки, а не эмодзи.** Все состояния, кнопки и подписи используют инлайновые SVG 24×24 со `stroke=currentColor` —
  тот же язык, что у иконок в шапке, преимуществах и подвале. Эмодзи в интерфейсе не используются.
- **Одна типографика.** Inter + `font-variant-numeric: tabular-nums` для дат, серийных номеров и цифр счётчика;
  моноширинный шрифт (третий в системе) не подключается.
- **Тихие состояния.** Счётчик поставки — нейтральная плашка, состояние передаётся иконкой и цветом строки;
  цветной фон остался только у «рейс задерживается» и у плашки «забронировано».
- **Ни одного инлайнового `style=""` на страницах.** Повторяющиеся приёмы вынесены в классы-утилиты:
  `.section--white` / `.section--soft` (фон секции), `.header-left`, `.header-nav a.is-current`,
  `.mobile-menu-phone`, `.lang-switch-mobile`, `.section-header.is-center` (заголовок секции по центру),
  `.section-more`, `.actions-center`, `.btn-block`, `.form-note`, `.breadcrumbs.is-offset`, `.footer-backlink`.
  Состояние мобильного меню задаётся классом `.menu-toggle.is-open`, а не стилями из JS.
  Единственная динамика — ширина полосы прогресса счётчика, её считает браузер.
- **Фон секций чередуется** (`--white` / `--bg` / тёмная статистика): «Контейнеры в пути» — `--bg`,
  «Как купить» — `--white`.

## Запуск

```bash
python3 -m http.server 8090     # → http://localhost:8090
```

Сборка не нужна, зависимостей нет. Открывается и просто как папка (все ссылки относительные).

## Демо-админка

`http://localhost:8090/admin.html` — макет будущей админки WordPress: можно сменить статус, срок поставки и дату прибытия
и сразу увидеть результат на витрине. Заявки с формы брони попадают в очередь: «Подтвердить бронь» ставит товару статус
«Забронировано», «Отказ» возвращает позицию в продажу.

> В демо заявки и правки сохраняются в браузере (localStorage) — реальные письма не отправляются.
> В WordPress заявка уходит письмом менеджеру на e-mail, а данные хранятся в базе.

## Проверка дизайн-системы

```bash
node tests/design-check.mjs      # из корня проекта
```

Скрипт падает, если: в интерфейсных файлах появились эмодзи; в CSS использован цвет вне переменных;
`var(--...)` ссылается на несуществующую переменную; в вёрстке есть `data-i18n`-ключ, которого нет в словаре
RU/RO; нарушена парность тегов; на странице появился инлайновый `style=""` или вернулся старый инлайновый
приём (`background:var(--bg)`, `display:none` на иконках, цвет активной ссылки).

## Тесты

```bash
node /путь/к/проекту/tests/ui-test.mjs
```

Покрыто: рендер каталога и карточки товара, все 4 состояния счётчика, фильтры и поиск по серии, полный флоу
«бронь — заявка — подтверждение менеджером — стикер на витрине», отказ от брони, пересчёт даты при смене срока,
переключение RU/RO, сброс демо-данных, а также остальные страницы (about, service, contacts, admin) —
отсутствие ошибок JS, инлайновых стилей и работа мобильного меню.
